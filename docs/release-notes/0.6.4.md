This is an early release. Please report what you hit and attach the log (F1 > System > Log).

**You need your own disc image:** Metroid Prime 2: Echoes USA (`G2ME01`), PAL (`G2MP01`), or Trilogy (`R3ME01` USA, `R3MP01` PAL). No disc image or game assets are included.

## What changed

- **Infinite ammo cheat.** F1 > Cheats, for all ammo or per ammo type (a box next to each ammo slider); also the `infammo` console command, `MP2_INFINITE_AMMO` and a bindable action. #16
- **Cinematic skip asks first.** With Skip cinematics on, the first press shows a Skip prompt with the button icon at the bottom centre; a second press skips. #17
- **Black bars beside 4:3 movies.** #17
- **Cutscene subtitles centred in widescreen.** #17
- **Quick resume boots straight into the saved room**, so an early save no longer replays the Landing Site intro.
