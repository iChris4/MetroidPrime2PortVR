This is an early release. Please report what you hit and attach the log (F1 > System > Log).

**You need your own disc image:** Metroid Prime 2: Echoes USA (`G2ME01`), PAL (`G2MP01`), or Trilogy (`R3ME01` USA, `R3MP01` PAL). No disc image or game assets are included.

## What changed

- **Scan visor locks on again on GPUs without full WebGPU support** (many Android phones, such as Adreno 6xx), with and without MSAA. #24
- **World animations move again.** Scrolling and animated textures were frozen. #21
- **Map screen fills the whole screen** in widescreen, without black bars. #23
- **Android memory card export works**: it now asks where to save the file instead of asking for a folder. #23
- **Sound effects no longer go silent** after quitting to the title screen and loading a save.
